# CSS Discord Botathon



## Intro

This repo holds the resources for the CSS Discord Botathon hosted on the 21st and 22nd November 2026.


## Set up 

Clone this repo with one of the below commands, depending on your setup:

```bash
gh repo clone MattyTheHacker/css-discord-botathon
git clone git@github.com:MattyTheHacker/css-discord-botathon.git
git clone https://github.com/MattyTheHacker/css-discord-botathon.git
```

Create a venv (or don't, you do you bro)

```bash
python -m venv .venv
```

And activate it:

```bash
source .venv\bin\activate
.venv\scripts\activate
```

Install [pycord](https://pypi.org/project/py-cord/)

```bash
pip install py-cord
pip install py-cord[voice]
```
